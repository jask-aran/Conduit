Conduit dashboard = New chat, on the split layout

The same frame as the project and workspace dashboards: a header with a context line and text shortcuts, the composer with a threads list under it on the left, and the right-hand column for places. It is also the New chat screen: New chat (sidebar, ⌘N) lands here with focus in the composer, and there is no separate empty-chat page. The chats list is every recent chat, the way the search overlay lists them. The right column gets a new element, a folder shelf for project folders, with workspaces and terminals under it as plain lists.

Recent chats = the search overlay's recentsEvery chat across projects, workspaces and no folder, newest first, grouped by day like the overlay. Each row: harness mark (lights on hover), title, where it lives, time. Running chats stay in place with dot + activity. All / Unread and sort as quiet heading actions.
Folder shelf (new element)Project folders as small folder glyphs in a wrapping grid, not tiles: no box, wash on hover, name and "N chats · last active" under the glyph, a live dot on the folder when one of its chats is running. Click opens the project dashboard; drag a chat onto it to move it. Ends with a dashed "New project".
Doubles as New chatNew chat opens this screen with the composer focused. Its "No folder ▾" chip picks where the chat will live; clicking a project in the shelf or a workspace row while the draft has text offers to start it there instead of navigating. Sending runs the existing send-from-dashboard move into the chat.
Workspaces stay a listWorkspaces carry more per row (glyph, branch, changes) and read better as rows than as folders, which also keeps "project folder" and "workspace" visually distinct. Terminals as on a workspace dashboard.
