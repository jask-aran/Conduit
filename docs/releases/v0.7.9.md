# Conduit v0.7.9

Hotfix for the launch screen and unclickable right-hand tool rail in v0.7.8.

- Removes the initial Conduit mark before mounting the interface, so it no
  longer remains visible behind panes after the splash fades.
- Prevents the launch placeholder from intercepting pointer events, restoring
  clicks on the right-hand tool rail.
- Keeps the intended launch fade. No server identity, pairing or user data
  changes.

Published for Windows x64, Android and the Linux x64 server. Existing v0.7.8
Windows installations can receive this hotfix through the normal updater.
