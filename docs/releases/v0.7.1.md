# Conduit v0.7.1

This patch release makes the desktop update in v0.7.0 installable.

## Desktop updates

- Store the updater archive uncompressed. The updater can only read Stored zip
  entries, so the v0.7.0 archive downloaded and verified and then refused to
  install with "Compression method not supported".
- Check the archive before signing it: every entry Stored, and named without a
  directory, so a release cannot carry an update no client can open.

## Upgrade note

No data migration is required. A desktop client on v0.7.0 cannot update itself
to this release, because the v0.7.0 artifact it would have to install is the
unreadable one; install this release's `.exe` directly. Updating from v0.7.1
onwards works in place.
