# Conduit v0.4.5

This release makes voice dictation and clipboard file attachments reliable
first-class chat features.

## User-visible changes

- Voice dictation supports managed Parakeet and Whisper models, microphone
  selection, microphone testing and playback, live waveform feedback, and
  Ctrl+Shift+D activation.
- Dictation supports push-to-talk and toggle modes. Transcripts insert at the
  caret, append when the composer is not focused, and remain selected for one
  backspace cancellation. Inserted dictations include word-boundary spacing.
- Audio capture now preserves data across startup and speech pauses, flushes
  the final captured audio before stopping, reports transfer and signal
  failures, and avoids treating normal short stops as microphone failures.
- Finalisation deadlines scale with recording length and model cost. Relaxed
  defaults give local full-precision models time to finish on weak hardware,
  with deployment-level timeout overrides.
- Voice settings persist the selected microphone and model. The shared
  waveform surface is used in both the composer and microphone test.
- Clipboard paste, drag and drop, and file attachment ingress use bounded,
  durable, chat-scoped files with safe names and browser coverage.

## Deployment note

No data migration is required. Restart Conduit to load the new voice and file
attachment behavior. Existing chats, sessions, credentials, recordings, and
settings remain in their existing data locations.

## Validation

The release passed 431 automated tests, TypeScript typecheck, the production
build, bundle checks, and PWA checks.
