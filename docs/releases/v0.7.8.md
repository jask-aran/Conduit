# Conduit v0.7.8

Servers have user-chosen names, builds identify the code they contain, and
restored panes no longer wait forever for a deleted chat.

## Server names

- Setup asks for a server name, defaulting to the saved name or machine hostname.
  `conduit-server name` changes it later without changing identity or pairing.
- The server publishes its name through the authenticated identity endpoint
  and LAN discovery. Clients use it instead of an address-derived label.
- Settings shows the server name, a short identity and its routes separately.
  Existing custom list labels remain; clearing one restores the server name.
- Dev and release code still share `~/.conduit/data`. Switching code does not
  rename the server or move its data.

## Build identity

- About replaces the fixed interface package version with build metadata.
  Release builds report the release tag and commit; development builds use
  the next patch version, UTC timestamp and commit, with a `modified` marker
  for tracked changes that have not been committed.
- Windows development builds stamp the interface and shell with the same
  version. Server release archives stamp the interface and server together.
- Removes the unused web package version without changing dependency versions.
- Fixes the component workbench's registry status when solid-components is
  listed under development dependencies.

## Pane restoration

- A saved pane whose chat no longer exists closes after the catalogue loads,
  or switches to another tab, instead of remaining on “Loading chat…”.
- Rechecks the current catalogue and pane before closing, so initial catalogue
  publication or a concurrent chat switch does not close a valid pane.

## Interface and installation

- Android and browser launch icons use the Conduit mark. Launch screens keep
  it visible until the interface arrives.
- Shared frosted dialogs replace separate overlay implementations.
- Installer dependencies and Python tools build while setup asks its questions.
  Local and network access remain available alongside optional remote routes.
