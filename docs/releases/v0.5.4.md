# Conduit v0.5.4

This release replaces browser-owned terminal replay with persistent,
tmux-backed Workspace terminals and makes Workspace faster to use on desktop
and mobile.

## Workspace terminals

- Keep several independent shells alive while their browser panes are hidden.
- Reattach to the current tmux screen without replaying a partial byte journal.
- Rename, detach, destroy, and inspect active terminal sessions from one menu.
- Take control of a terminal from another Conduit client.
- Use xterm WebGL rendering, reliable text paste, terminal zoom, and native
  authentication tickets.
- Clean up development terminal sessions during Conduit lifecycle operations.

## Workspace interface

- Expand Workspace across the chat area while preserving the sidebar.
- Put Files, Source Control, Artifacts, and Terminal in the Workspace header.
- Keep narrow mobile tabs evenly spaced and collapse their labels to icons.
- Resize the file preview or working-tree patch to almost any vertical split.
- Recover stale new-chat routes after a server restart.

## Deployment note

No data migration is required. Deploy `ghcr.io/jask-aran/conduit:v0.5.4` and
restart Conduit. Workspace terminals require tmux 3.3 or newer on the server
host. A Conduit server restart ends its managed terminal sessions.
