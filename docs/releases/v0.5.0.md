# Conduit v0.5.0

This release delivers the new responsive chat surface, live composer material,
expanded local voice dictation, and the Incremark Advanced renderer.

## User-visible changes

- Desktop adds a context-usage gauge with the configured metric details in its
  popover. Mobile keeps those details in More.
- The composer has responsive 22px geometry, a 44px mobile base height, and
  material-aware desktop controls. Frosted Live is available as a composer
  material; desktop header and Follow controls use the same material.
- Mobile has a full-bleed chat surface, a compact composer, and an overflow
  header. It keeps the header plain rather than wrapping it in a desktop pill.
- Voice dictation adds managed local runtimes, microphone diagnostics,
  waveform feedback, selected completed dictation, and resilient archive
  settlement.
- Incremark Advanced is available as an experimental transcript renderer with
  controlled pacing and bounded math rendering.
- Update app now reloads after its service-worker update check. Workspace close
  restores focus safely before the panel becomes hidden.

## Deployment note

No data migration is required. Deploy `ghcr.io/jask-aran/conduit:v0.5.0` and
restart Conduit. Existing chats, projects, settings, credentials, recordings,
and managed model downloads remain in place.

## Validation

The release commit passed TypeScript typecheck, the production build, bundle
and PWA checks, focused local-auth and Windows DevTools tests, and a browser
workspace-close accessibility check.
