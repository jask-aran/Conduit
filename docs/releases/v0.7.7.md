# Conduit v0.7.7

Conduit installs with one command and runs as `conduit-server`, a daemon on
any Linux or macOS computer you own. The container is gone. Devices pair by
QR code.

## Install

```bash
curl -fsSL https://get.jask-aran.com/conduit | bash
```

- Downloads the release for this platform (Linux x64 and arm64, macOS arm64;
  Windows inside WSL) and the Node it was built with into
  `~/.local/share/conduit`, checking its SHA-256 and its signature against the
  release key. Nothing needs root.
- Setup asks for a password, a port and how Conduit will be reached -- just
  this computer, Tailscale (installed and served if wanted), a tunnel or
  reverse proxy, an SSH tunnel, or the local network -- then starts it as a
  systemd user service or launchd agent.
- `--sandbox` installs a second, throwaway daemon with its own data, port and
  service.

## conduit-server

- `status`, `start`/`stop`/`restart` (waits for live answers), `logs` with
  `--since` and `--errors`, `doctor` with `--fix`, `open` (signed in),
  `connect`, `projects add`, `sessions` and `revoke`, `config`, `password`,
  `backup`/`restore`, `report`, `update` (with a beta channel) and
  `rollback`, `completion`, `uninstall`.
- `use dev <clone>` runs a development checkout on the same daemon, data and
  port; `use release` returns to the installed release.

## Pairing

- `conduit-server pair`, and **Pair a device** in any signed-in client's
  server menu, show a QR of a one-time, five-minute sign-in link on the route
  other devices are likeliest to reach.
- A phone camera opens it signed in; the app's **Scan QR code** (or the link
  pasted into the address field) pairs the app.

## Data

- State moves to `~/.conduit/data` for every checkout and install. The
  Docker image, Compose files, Caddyfile and deploy scripts are removed.
