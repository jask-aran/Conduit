# Conduit v0.5.3

This release adds the first installable Android app and improves the mobile
interface in both the app and PWA.

## Android app

- Connect the bundled Capacitor app to one HTTPS Conduit server.
- Sign in with the existing Conduit password and keep the native session in
  Android secure storage.
- Use authenticated chat streams, terminals, dictation, and attachments.
- Reconnect promptly when Android returns the app to the foreground.
- Enter the server address and password in one progressive setup form.
- Download the signed Android APK and SHA-256 file from this GitHub release.

## Mobile and model selection

- Open and close both mobile sidebars with edge swipe gestures.
- Keep all header controls on-screen while the status waveform uses the
  remaining width.
- Open a new chat directly from the mobile header.
- Refresh installed provider models when providers change.
- Open and close the model selector with Ctrl+X.

## Deployment note

No data migration is required. Deploy `ghcr.io/jask-aran/conduit:v0.5.3` and
restart Conduit. The Android app requires this server version for native
authentication and WebSocket tickets.
