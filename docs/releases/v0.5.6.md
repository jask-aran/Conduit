# Conduit v0.5.6

This release makes Conduit a direct browser terminal and improves terminal use
across desktop and mobile clients.

## Terminal experience

- Open the new dashboard at `/` without starting a chat process.
- Open a home-scoped terminal directly at `/terminal`.
- Return to the dashboard from the Conduit sidebar heading.
- Use the same terminal session manager, transport, renderer, reconnection, and
  focus behavior in the standalone route and Workspace panel.
- Enter browser fullscreen from the standalone terminal to capture browser
  keyboard shortcuts.
- Use the mobile terminal key bar for common terminal keys and combinations.

## Terminal shortcuts

- Define command shortcuts once and use them from every Conduit client.
- Run a shortcut in the current shell or create a named shell for it.
- Reorder, rename, and remove shortcuts from the terminal control bar.
- Keep shortcut and terminal rename dialogs usable in standalone and browser
  fullscreen modes.

## Deployment note

No data migration is required. Existing preference files gain an optional
`terminalShortcuts` field through normal preference normalization.
