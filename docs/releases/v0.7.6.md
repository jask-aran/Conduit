# Conduit v0.7.6

The main pane holds up to three panes of chats, pages, files, tools and
terminals, with tabs; the workspace panel becomes a dock on a right-edge rail;
Claude Code joins the harnesses; and the interface is redrawn around one
sidebar language, frosted overlays and a keyboard that reaches every region.

## Panes and the dock

- The main pane holds up to three panes. Each can show a chat, the dashboard,
  a project page, a harness page, the Computer page, a file viewer, a tool or a
  terminal, with its own composer and session. Panes resize by their edges down
  to their document's minimum, and ease open and closed.
- A pane of chats holds up to five tabs; a file viewer holds up to five files
  and shows one or two side by side. Ctrl-click keeps a tab, Alt opens beside,
  and closing a tab shows the one used last. Tabs survive a reload.
- Headers, tabs, sidebar rows, files and tools drag onto panes: an edge opens a
  new pane there, the middle swaps or replaces, and a pill at the pointer says
  which.
- The workspace panel is the dock, opened from a rail on the right edge. It
  follows the pane with the keyboard. Folded panes wait as lettered tiles in
  the rail's foot.
- Alt+[ and Alt+] step a pane's tabs, Alt+Shift+[ and ] step panes, and
  Ctrl+Shift+2 moves between panes. The address carries every pane, and Back
  restores them.

## Claude Code

- Conduit drives Claude Code through the Agent SDK: it streams, steers,
  queues, compacts, forks, reports usage, takes attachments, and asks its
  approvals and questions on the composer.
- A turn Claude Code starts by itself is shown on the notice that started it.

## Harness pages and untracked threads

- A harness's page lists its threads In Conduit and Not in Conduit. An
  untracked thread opens as a chat page of its own, takes prompts from its
  composer, and closes its process once no page drives it.

## Dashboards and the sidebar

- The Conduit dashboard is the new-chat screen, and project and workspace
  pages take the same split layout: chats, changes, terminals and files, with
  filters by profile and harness. The layout changes at the width its controls
  need and glides between one column and two.
- The sidebar splits Conduit and Computer, marks each chat with its harness,
  and moves by keyboard: arrows, into projects, range selection and the row
  menu.
- The composer has a folder button that puts a chat in a project or
  workspace.

## Turns and the trace

- A turn's trace header says what it is doing, how it ended, how long it took
  and its work by kind. The opened trace is a trail of one line per step.
- A thinking orb moves with the turn; a settled one turns slowly, and one that
  did not finish sputters.
- Every harness states how a turn ended. A stopped turn is one row, its
  discarded answer the trace's last, struck-through step.
- Questions and approvals take the composer's place, one at a time.

## Streaming math

- Formulas draw as they arrive: open environments, `\left` and cut-short
  arguments are closed for the partial, so a long aligned block grows row by
  row instead of appearing whole.
- Formulas already closed no longer blink out while the next one is written,
  and the rest of an open formula can no longer show as raw TeX.
- A formula still arriving is patched from KaTeX's own render tree rather than
  rebuilt, which keeps a long block's frames near the 144Hz budget.
- Streaming has a Fade option: each new word fades in as it arrives. Formulas
  still grow piece by piece, or, with "Fade formulas in when complete", appear
  whole with one fade once closed.
- An answer's copy and regenerate buttons and its time wait until it has
  finished appearing, then fade in, instead of jumping at the bottom of a
  fast stream.
- A stopped answer that ends inside a formula draws what was written of it,
  not raw TeX. Formulas opening on a digit or a space (`$2^{10}$`,
  `$ \infty $`) and `$$…$$` mid-line are read as math, while prices stay
  prose.
- A chat of formulas opens with the ones on screen drawn first, and a chat
  opened before draws its math with the page from a kept copy.
- Chat search's preview draws the answer's formulas.

## Interface

- Menus, palettes, chat search, settings and dialogs share one frost shell.
  The current choice is bold, and focus is a wash, not a ring.
- Chat search is a keyboard-first browser of every chat, with a preview of the
  last turn. The command palette groups commands by intent.
- Settings are one-line rows grouped by heading, and save as they change.
- The leader moves to Ctrl+G and shows the current region's keys;
  Ctrl+Shift+1–3 go to the sidebar, main pane and dock.
- The UI fades in on first open once the page is laid out, and a new chat's
  composer travels to its place on send.

## Updates and restarts

- Windows development builds update through the server the client uses.
- A restart announces the rebuilt client first, so open browsers install it,
  and waits out a starting server instead of failing.
- Terminal sessions survive a Conduit restart.

## Performance

- The server's workspace watch walks the tree on a worker thread, so opening
  a file no longer waits seconds behind it.
- Style rules that taxed every DOM change exist only while their motion runs.
- Pane-edge and divider drags no longer force layout each frame, idle orbs
  share one slow loop, and scrolling a transcript back down stays within the
  frame budget.
- A long streamed answer no longer gets slower as it grows: settling,
  following the tail and virtualising cost the same at its end as at its
  start, formulas included.

## Test profile

- Its chats are kept on disk: they reload and survive a restart, tools
  included.
- Two KaTeX replies can be replayed word for word at a real model's pace.

## Fixes

- A project dashboard no longer fails when a recent chat is on a harness
  with no threads to list.
- The dock no longer jumps while its edge is dragged.
- An answer keeps the same spacing at every width, so dragging a panel across
  the wide-layout width no longer jumps the transcript.
- Tables line up with the text column's right edge in a narrow pane, and a
  formula wider than its column scrolls from its start instead of being cut
  off at both ends.
- Pressing a panel handle no longer nudges formulas sideways, and a chat of
  formulas no longer shifts after it loads.
