# Conduit v0.4.7

This release fixes managed Parakeet runtime installation in the unprivileged
production container.

## User-visible changes

- Runtime extraction no longer attempts to restore archive ownership or
  permission metadata that the Conduit container cannot change.
- Interrupted managed-model staging remains resumable. Existing verified
  Parakeet downloads can continue without a full re-download.

## Deployment note

No data migration is required. Restart Conduit with `v0.4.7`. If the previous
Parakeet install left an incomplete staging directory, it is safe to remove
only that model's `.installing-parakeet-tdt-0.6b-v3-fp32` directory before
retrying the installation.

## Validation

The release passed 433 automated tests, TypeScript typecheck, the production
build, bundle checks, and PWA checks.
