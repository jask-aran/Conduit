# Conduit v0.5.1

This release republishes v0.5 with a compatible native transcription build.

## Deployment note

No data migration is required. Deploy `ghcr.io/jask-aran/conduit:v0.5.1` and
restart Conduit. Existing chats, projects, settings, credentials, recordings,
and managed model downloads remain in place.

## Validation

The release commit passed TypeScript typecheck, the production build, bundle
and PWA checks, and focused voice, composer-material, and performance-shell
tests. GitHub Actions publishes the Linux container and runs Fast checks.
