# Conduit v0.7.5

Conduit drives OpenCode and fx beside Pi and Codex now, a client can tell the
server it paired with from one that only claims to be it, and the terminal
comes back from a restart with the commands it was running.

## OpenCode

- Conduit drives OpenCode 2.0.14 and offers its favourite models.
- Turns follow OpenCode's event stream instead of polling, and stream live:
  text, reasoning and each tool as it runs. A dropped stream is recovered, and
  a turn fails plainly after repeated failures rather than hanging.
- Long chats load older turns as the reader scrolls up, and a turn is never
  split across a page.
- OpenCode's permissions and questions are answered in its own terms, with an
  auto-accept option. Tool calls are listed in History as Pi's are.
- Attachments are sent as file URIs, which OpenCode reads itself.

## fx

- fx notices -- context, system and error text sent on the same channel as the
  reply -- stream into the trace instead of joining the answer. The answer is
  the reply fx saves, and reasoning streams as reasoning.
- A reload keeps each turn's ids, a running fx tool shows in the trace, and an
  fx process that dies ends its turn and its chat's session instead of leaving
  them waiting.

## Every harness

- Each profile shows its harness's mark. Codex is drawn in one colour outside
  its dashboard tile, and Conduit's own mark is a bold C.
- Effort is set on a slider that takes any ordered list of levels, in the
  phone's options menu and the desktop model menu. A tap on its label opens
  the plain list.
- The dashboard composer offers the chosen profile's controls, attachments
  included.
- The chat backend contract covers OpenCode and fx, and neither claims a
  replay it does not do.

## Trusting a server

- A server answers over TLS on 4319 with a self-signed leaf naming its
  addresses, attested by its identity key. The leaf is re-issued as addresses
  change or it nears expiry.
- The Android app pins that certificate in its WebView. The fingerprint is
  checked against the identity the connection authenticated with before it is
  stored, never after.
- Ed25519 verification ships with the client, so the server proof and the pin
  work on WebViews older than Chromium 137, which have none.

## Terminal

- A shortcut can be marked "Run on start" and is typed into the shell
  /terminal opens by itself, so a restart brings back what was running.
- A restart while on /terminal no longer flashes the old screen or pulls the
  terminal away again after it returns.
- The header has one status indicator and the shortcut editor one kind of
  dropdown, in the app's own styling.
- Conduit stops, starts and restarts past a terminal tmux server that stopped
  answering.

## Phone

- The Workspace panel keeps clear of the status and navigation bars, and its
  controls are sized for a finger.
- The Android app can use the microphone for dictation.
- A tap on the options menu while a submenu is open only closes the submenu
  instead of choosing what was under the finger.

## Fixes

- A truncated `identity.json` or `leaf.json` no longer stops the server from
  starting, and a misbehaving child process no longer takes it down.
- A closed Workspace panel no longer shows its edge.
- A reload no longer overlays the live turn on an older page of a transcript.
