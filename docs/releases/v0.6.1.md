# Conduit v0.6.1

This maintenance release restores Fast checks after v0.6.0 and reduces avoidable test and release work.

## Test reliability

- Update chat-search, runtime-policy, and configuration fixtures to match the current contracts.
- Keep process, terminal, deployment, swipe, waveform, and composer behavior coverage.
- Replace implementation-text checks for the component workbench with an executable CLI check.
- Stop config tests from probing Host Pi and remove the auth integration test's limiter wait.
- Remove an obsolete terminal-performance fixture and a duplicate harness run from Fast checks.
- Schedule desktop and mobile browser cases only on their applicable Playwright projects.

## Release performance

- Build the signed Android APK and Linux container in parallel, then create the release after both succeed.
- Cache Gradle and BuildKit work between GitHub Actions runs.
- Keep changing release metadata after stable container dependency and runtime layers.
- Keep publication independent from Fast checks while the revised checks establish a reliable pass history.

## Upgrade note

No application behavior or data format changes. No migration is required.
