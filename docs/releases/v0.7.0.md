# Conduit v0.7.0

This release adds a Windows desktop client and makes the server authoritative
for the transcript. It is the largest release so far; the sections below name
the themes, and `git log v0.6.1..v0.7.0` is the full record.

## Windows desktop client

- Ship a Tauri shell around the same client the browser and Android run.
- Keep the sign-in token in the OS credential store, never in web storage.
- Let a client on the same machine reach a server over loopback, and offer it.
- Give the window one lifecycle: tray, close-to-tray, single instance, autostart.
- Scale the interface by the webview's zoom, and paint the title bar to the frame.
- Hold two commands system-wide: Open Conduit, and New chat from anywhere.
- Update in place from a signed artifact this release is the first to publish.

## Server-authoritative transcript

- Let the server state the transcript, and stop the client inferring it.
- Give every message an identity Conduit owns, whichever harness wrote it.
- Rebuild how a chat gets its agent, and let the server decide when one runs.
- Decide a chat's interface from its harness manifest rather than its process.
- Settle interrupted and forked turns into the transcript before the next starts.
- Replay a reconnecting browser the answer rather than the deltas it missed.

## Streaming and rendering

- Send every frame by one path, paced to the reader's frame rather than the
  backend's, and drop frames carrying nothing.
- Expand one run of tools without expanding all of them.
- Render an inline comparison as one document holding both sides.
- Move the context gauge into the composer.

## Upgrade note

No data migration is required. The desktop client is new, so there is nothing
to upgrade from; install it from this release's `.exe`. Its updater accepts
only artifacts signed by the key compiled into the build, so a client from
before this release cannot be updated in place and must be reinstalled.
