# Conduit v0.5.5

This hotfix restores Workspace terminals in containers that use tmux 3.5.

## Terminal compatibility

- Parse tmux session metadata with a printable field separator.
- Prevent tmux 3.5 format sanitization from hiding live terminal sessions.
- Keep newly created terminal records synchronized with their running tmux
  panes.

## Deployment note

No data migration is required. Deploy `ghcr.io/jask-aran/conduit:v0.5.5` and
restart Conduit. The restart ends terminal sessions left by v0.5.4; create new
terminals after deployment.
