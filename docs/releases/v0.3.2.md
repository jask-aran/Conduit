# Conduit v0.3.2

This release improves chat, Workspace, rendering, testing, and agent runtime
reliability across the full change set since v0.3.1.

## User-visible changes

- Workspace terminals now handle resize, focus, stop controls, PTY replay, and
  reconnect lifecycle more reliably.
- Sidebar and Workspace panels use coordinated shell-edge motion. Desktop
  collapsed rails remain usable, mobile panels keep full-screen geometry, and
  transcript layout no longer jumps during panel changes or resize.
- Typewriter and Synthetic rendering share stable tail-follow behavior, with
  improved frame pacing, Markdown/math/table streaming, and scroll anchoring.
- Workspaces can show a custom icon, monogram, preset color, or custom color
  from the dashboard.
- Local browser QA now uses a bounded agent-browser wrapper and clearer
  deterministic browser checks. Auth route canaries and release validation are
  more reliable.
- Assistant and Coding now resolve search routing from the selected model:
  OpenAI models use OpenAI search first with Brave fallback, while other models
  use Brave.
- Assistant and Coding share the provider-neutral `web-research` skill. It
  favors focused, bounded research through the configured web tools and avoids
  a second Bash or `curl` search path.
- Model changes that cross a runtime-profile boundary restart idle isolated
  sessions safely and reject busy transitions without changing the active
  model.

## Deployment note

No data migration is required. Restart Conduit to load the new templates and
model-profile routing. Existing Pi credentials, sessions, and canonical search
settings remain in their existing data locations.
