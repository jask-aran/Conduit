# Conduit v0.5.7

This release replaces the old landing surfaces with compact dashboards and
makes active work easier to reach from the sidebar.

## Dashboards

- Start a new chat from the Conduit dashboard without leaving the page.
- Open recent chats, recent Workspaces, and live terminals from one bounded
  desktop or mobile surface.
- Use Workspace dashboards with the same compact recent-chat presentation,
  scoped activity, files, Git state, and terminal access.
- Load dashboard chat data in the background so later navigation does not wait
  for session initialization.

## Sidebar

- Pin chats, projects, Workspaces, and live terminals in one persistent section.
- See each live terminal's shell name, active command, and recent activity.
- Open a Workspace terminal beside a new chat in its original Workspace.
- Open the Conduit dashboard from the full-width sidebar entry.

## Login

- Use the new flat, borderless password surface on a black background.

## Deployment note

No data migration is required. Existing preference files gain an optional
`sidebarPins` field through normal preference normalization.
