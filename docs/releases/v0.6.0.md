# Conduit v0.6.0

This release expands Workspace and Computer, stabilizes panel state, and improves app updates.

## Workspace

- Browse a canonical Workspace tree with icons, filtering, refresh signals, and file actions.
- Open two files side by side. Preview images, audio, video, PDFs, CSV, Markdown, and code.
- Edit text files, compare one file in Diff, and retain the combined Git patch view. Git work
  is bounded, cancellable, cached per Workspace, and loaded on demand.
- Preserve panel visibility, tabs, files, geometry, and maximized state per Workspace. Panel
  motion now keeps the transcript and composer coherent.

## Computer and navigation

- Browse the host through a tiled Computer explorer, and create folders and Workspaces there.
- Return from Terminal View to the prior route without losing Workspace or sidebar state.
- Start chats from dashboard pages in the correct Workspace scope.
- Reorder the sidebar, align its actions, and remove the accidental edge toggle target.
- Persist interface scale, chat sorting, collapsed groups, sidebar state, and other UI
  preferences through the server while retaining immediate local navigation behavior.

## Reading and rendering

- Upgrade streaming Markdown, math, tables, code highlighting, citations, currency text,
  user-message collapse, transcript anchoring, and follow-tail behavior.
- Reduce transcript reflow during panel motion and large animated content. Remove obsolete
  renderer harnesses and retain focused checks for supported rendering paths.

## Runtime and installed app

- Synchronize terminal creation, takeover, exit, and removal across clients.
- Add reliable Check for Updates to the account menu. Detect a current bundle without a false
  activation error, and activate a newer service worker in one action.
- Recover isolated sessions whose persisted model is outside the current scope. Improve scoped
  model, preference, project, session, attachment, and Workspace path handling.

## Upgrade note

No data migration is required. This release publishes the Linux container and signed Android APK.
