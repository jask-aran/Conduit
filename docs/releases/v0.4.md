# Conduit v0.4

This release makes chat search and management a first-class Conduit surface and
adds the extensible shortcut system that supports it.

## User-visible changes

- Chat search now has one shared dialogue for direct search, View all chats,
  scoped folders, and future search sources. Query filters support chat scope
  and folder or workspace names.
- Chat management supports keyboard and mouse entry for bulk selection, move,
  and delete, plus focused single-chat rename, move, and delete actions.
- Search navigation expands a collapsed parent folder when it opens a chat and
  keeps folder collapse independent from the active chat.
- Search and command palettes keep their focus and geometry across Escape,
  Backspace, confirmation, edit, move, rename, desktop, and mobile flows.
- The command palette now has a browser-aware shortcut manager with settings
  search, recording, conflict warnings, context-specific commands, and saved
  overrides. Ctrl/Cmd+Shift+K opens or closes Chat search by default.
- The header exposes separate Search and Command Palette buttons with distinct
  icons. Browser conflicts such as Firefox Web Console ownership are explained
  in Settings → Shortcuts.
- Provider failures, recovered sessions, thinking-level migrations, runtime
  diagnostics, and non-OpenAI search fallback paths now fail more clearly and
  recover more safely.
- Deployment, repository setup, mobile layout, and browser test coverage were
  updated for the larger chat and shortcut surfaces.

## Deployment note

No data migration is required. Restart Conduit to load the new chat-search and
shortcut behavior. Existing chats, folders, sessions, credentials, and search
settings remain in their existing data locations.
