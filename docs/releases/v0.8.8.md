# Conduit v0.8.8

A terminal on a device near you is typed into on that device, not through
the hub, and a file read from it is sealed over a plain LAN. The hub sets
up its own LAN names from Settings. The Conduit durable agent picks up
more of what Pi did: its settings, extension commands and dialogs, a full
history tree, and background subagents that report back. Subagents get
their own lists. Settings is reworked page by page, and Sign in with
ChatGPT works.

## Upgrading

- Update `conduit-node` and the apps along with the server. A v0.8.7 node
  or app still connects, but only an updated node serves terminals and
  sealed reads directly. A v0.8.7 client reads an updated node's files
  through the hub over a plain LAN.
- The legacy OpenAI Codex provider is no longer used. The Assistant,
  Runtime and Coding profiles name the same models under OpenAI. Sign in
  with ChatGPT under Settings › Models & accounts › Add an account ›
  OpenAI, then enable the models again.
- Web search moves to pi-web-access 0.45. An existing `web-search.json`
  keeps its route; Conduit names it again whenever a search key is added
  or removed.

## Terminals and reads on nearby devices

- A terminal on a device the client can reach is attached on the device
  itself. Every frame is sealed end to end, so it works over a plain LAN
  too. Anything that fails before the terminal answers goes through the
  hub, as before.
- Direct reads over a plain LAN are sealed the same way. Loopback, https
  and the tailnet stay plain.
- Grants are signed with a key each node run makes and gives the hub only
  over https or loopback, and a node's proof is bound to the address it
  was reached on.
- A node paired by a LAN address in plain HTTP moves to TLS pinned to the
  hub's identity from its second run.
- WSL relayed by the Windows app serves direct reads and terminals as its
  relay does.
- A device's home terminal opened from the sidebar or a page works again.

## LAN names from Settings

- Settings › Devices › Network sets up LAN names: a name below a
  Cloudflare zone, with a token scoped to that zone's DNS or the hub
  machine's signed-in `cf`. The hub issues and renews the certificates
  itself and sends nodes theirs. Hubs set up by the scripts keep working.

## The Conduit durable agent

- It honours the Pi agent's `settings.json`: retry, compaction, steering
  and follow-up modes, and the shell. `/compact <instructions>` passes
  them to the summary.
- Pi extensions' slash commands and the profile's prompt templates are
  offered and run. An extension's select, confirm, input and editor
  dialogs use the chat's question card; its notices are toasts.
- The history tree shows tool steps, compactions and resets. Markdown
  export includes each tool call and its output.
- A subagent can run in the background: it reports back to the chat when
  it finishes, and the agent can message, wait for or stop it. A chat's
  spend counts failed attempts, compaction and its subagents.

## Subagents

- A turn's subagents are a list under its head: what each is doing now,
  or how it ended and what it spent, and its time. A chat's background
  agents ride on its composer, one line each, with Stop.
- Each opens its transcript beside the chat as a read-only chat of its
  own.

## Devices away

- Offline is shown where the workspace is named, on its dashboard and the
  chat header, instead of over every composer in it.
- A workspace or file tab on an offline device waits for it to come back
  instead of asking every 1.5 s. It no longer shows an error toast.
- A page reads a device workspace's images, PDFs and media from the
  device when it can.
- Every tab now knows when a device is offline, not only the first.

## Web search

- pi-web-access 0.45: its tools take about 1.1k tokens a request instead
  of 2.8k, and `source_check` shows its passages.
- Settings › Web search sets:
  - falling back on empty or off-site answers too;
  - skipping off-topic results, checked by Cloudflare's Clef;
  - a time limit for one search;
  - reading values off pages (extract mode).
- The last two need Cloudflare Workers AI, added with its account ID in
  Settings.

## Settings

- Sign in with ChatGPT works: Conduit gives Pi the installation ID it
  asks for.
- Every key, cookie and sign-in is one kind of row: Replace or Add opens
  its field in place, and Esc puts the row back without closing Settings.
- Models & accounts lists connected accounts with their own actions. Add
  an account and Add a provider have a search.
- Appearance is split into Interface and Reading, with a new Transcript
  size. Hardware acceleration says whether it is on.
- Counts are selects. Voice's shortcut is recorded like the Shortcuts
  page's, and Shortcuts has an Assigned only filter.
- Runtime lists the live agent processes by chat, with Stop.
- The system prompt editor scrolls inside itself.
- Devices puts identical browser tabs on one line and names a shared
  folder instead of showing its whole path.
- The server address field no longer takes the browser's autofill.

## Chats and turns

- A prompt taken mid-run (a steer, a follow-up, a subagent's report) is
  timed from where it was taken, instead of reading "Done · 0ms".

Published for Windows x64, Android and the Linux x64 server. Installed clients
bundle their own interface and need a client update to receive these changes.
