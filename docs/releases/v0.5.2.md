# Conduit v0.5.2

This release makes model selection a fast, scoped keyboard workflow and
stabilises interrupted-chat status.

## Model selector

- Open the top-level Model selector from its configurable application shortcut.
- Search all installed provider models with fuzzy matching.
- Scoped models appear first and are the models available to the composer.
- Press Cmd/Ctrl+F to add or remove the highlighted model from scope.
- Press Enter to select a scoped model for the current chat.
- The selector keeps its search, focus, grouped results, and shortcut footer
  while scope changes save.
- The ordinary command palette no longer mixes model selection into commands.

## Chat and UI

- Stopped generations show `Interrupted · Ready` until a new response starts.
- Context usage and mobile renderer controls are more reliable.
- Consecutive completed assistant entries render as one answer.

## Deployment note

No data migration is required. Deploy `ghcr.io/jask-aran/conduit:v0.5.2` and
restart Conduit. Existing chats, projects, settings, credentials, recordings,
and managed model downloads remain in place.
