Palette sketch

The command palette, chat search and model selector, redrawn in the language Conduit has grown into since they were built: a glass card like the leader menu and composer, the sidebar's rows and group labels, harness marks, and the orb. The shortcut rail at the foot stays, tidied. Each proposal is live HTML over a mock window, beside the palette as it is now.

What changes, in short

  • Material. A glass card instead of the flat grey slab. Smoked glass (recommended) is the composer's recipe darkened so dense rows stay legible over a busy transcript; the switch above shows the composer's frost as-is and a minimal solid-but-lit option.
  • It stays put. The card is pinned near the top, not centred, so narrowing the list while typing shrinks it from the bottom instead of making it jump.
  • Where you are is a path, not a row. COMMANDS › CHATS crumbs in the leader menu's style replace the Search › prefix and the big Back row. Esc or Backspace on an empty query goes up one level; a crumb goes straight there.
  • Rows are one line, in the sidebar's language: sentence-case group labels, a 12px title, and quiet mono meta on the right. Chat search fits about twice as many chats.
  • Row shortcuts are keycaps, the same as the rail, not grey text like Ctrl Shift C.
  • Chats show their harness mark instead of the same speech bubble on every row. A chat that is running shows its orb, the current chat is white and semibold (as in the sidebar), and chats are grouped by day with a short time on the right.
  • Typing highlights the match: matched letters are white and the rest of the title dims.
  • Commands are grouped by intent (This chat, Go to, Create, View, App) instead of one long COMMANDS list, with context actions first.
  • The rail. The leader menu's keycaps and hairline. Actions you can click are white, and navigation keys sit at the right. Latest/Created moves up to the search row as a segmented choice.
  • Selecting several chats uses the wash on each selected row, with no checkbox column (DESIGN.md already says this; today's palette breaks it).

Search — decided

Search is its own surface (Ctrl Shift K), not a page of the command palette. The bar is a search icon, then chips, then the query. A scope is only ever a chip (in:Japan), and so are activity views (is:unread, is:running). Backspace on an empty query removes the last chip, and Esc steps out. The rail holds keys only. The preview column is allocated from the start and toggled with Ctrl P, remembered per device; below ~900px it is hidden.

Search — root

Recent (five chats), then Folders: Chats, projects and workspaces in one list, each with a live or unread dot, a count and its last activity. Right expands a folder to five chats and a Browse all row. Enter on a folder scopes into it, and Ctrl Enter opens the project.

Plan

  1. Material and placement (styles.css command block): one .palette-material class owns the smoked glass, used by .command-shell and the delete confirmation. The shell is pinned at the top (align-items: start, top offset) instead of place-items: center. The dim behind drops from 55% to ~42%. It arrives with the leader menu's rise and fade (220ms) and leaves quickly.
  2. Search row (command-menu.tsx): crumbs from pageMeta replace .command-page-prefix, and the page-back row goes. A leading search icon at the root. Filter chips become mono tokens. The sort toggle moves here from the rail.
  3. Rows: one line everywhere, with the chat rows' two-line clamp and <small> detail line removed. Keycaps come from the same formatter the rail uses. HarnessMark on chat rows. Day groups and short times from chatSortStamp. The current chat and running chats come from the sidebar's existing state.
  4. Match highlighting (palette-search.ts): return the matched ranges with the rank so the label can wrap them.
  5. Command groups (palette/command-registry.ts): split commands into This chat, Go to, Create, View and App. Context actions sort first when they apply.
  6. Edit mode: drop .command-select-mark; a selected row takes the wash.
  7. Rail (command-hint-bar.tsx): the leader menu's keycap and hairline tokens. The bordered Edit chats button becomes a white actionable hint. Navigation keys are pushed right.
  8. DESIGN.md: rewrite the Palettes paragraph (glass allowed here, crumbs, one-line rows, sentence-case group labels, row keycaps, pinned top) and drop "no glass on palettes".
  9. Preview column: a separate step, if wanted.

Open choices: which material; the preview column now, later or never; sentence-case group labels (sidebar) or keep the uppercase tracked ones.
