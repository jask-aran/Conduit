## Performance evidence

Frame intervals come from consecutive animation-frame timestamps; `resizeUpdateMs` measures the synchronous width
write plus forced geometry read, not every later observer or paint callback.

## Implementation facts and risks

- `chat-art-draw.ts` already used WebGL 2. Waves now renders one fragment per dither cell. Each pane clips a fixed
  canvas instead of reallocating a cropped canvas during resize. Static pictures reuse pixels; scenes copy one new
  frame. Resize observers update geometry using the current frame instead of rendering the shader twice.
- Static pictures keep larger buffers per pane. Real-phone GPU performance and memory pressure remain unverified.
- `mountTranscriptVisibility` accepts an optional row selector, so Jbot can share the existing block visibility and
  pane-motion handling. Jbot tail-follow holds while visibility/motion changes settle. Check scrolling, live updates,
  closing/reopening, nested content expansion and find behaviour when changing this further.
- Jbot's auxiliary panel builds when first needed and stays mounted; the old 1.5-second hidden-build timer is gone.
- Waves is Conduit's custom shader. Stacked dither is a separate upstream engine, pinned in
  `conduit-web/vendor/stacked-dither/COMMIT`; its local WebGL change retains the drawing buffer for pane copies.
- Waves defaults for a client without saved choices: blue, 1×, 2px. Existing saved choices remain. Meteor field no
  longer syncs from server UI preferences; background choices are client-side.
- Animated choices have GitHub icons. Sharks' cell-grid draw call was removed. Stacked dither copies use pixelated
  scaling. Animation controls cover wave speed/cells, Waves colours, upstream palettes/quiet centre, sharks and spiders.
- VPS: `ssh jask-vps`, dev clone `/root/conduit-dev`, service `conduit-server-dev`, port 4311, state `/root/.conduit-dev`.
  A separate release service also runs. The missing OpenAI module at midday coincided with `npm ci` replacing live
  dependencies. The module later existed and imported successfully. The new stop-before-install fix is local only.
  It trades update downtime for safety; a separate release directory would be needed for a later zero-downtime design.
